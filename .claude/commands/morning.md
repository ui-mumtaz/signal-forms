# morning.md (example skill)

## Steps
1. Check git log (last 24h)
2. Summarize yesterday's work
3. List open PRs to review
4. Check today's calendar
5. Format as standup bullets

## Output format
Print exactly in this style — a progress list of what was loaded/run, then bullets, then a closing line:

```
$ morning prep
▸ Loading CLAUDE.md ............. ✓
▸ Loading memory.md ............. ✓
▸ Connecting Gmail via MCP ....... ✓
▸ Connecting Calendar via MCP .... ✓
▸ Running skill: morning.md ...... ✓
